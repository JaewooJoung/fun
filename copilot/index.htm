agentmaker.wasm 선택

1. Title 제목

에이전트 이름입니다. 무엇을 도와주는 비서인지 한눈에 보이게 짧게 쓰세요. 예: 회의 준비 비서, 주간 보고서 도우미

2. Summary 요약 / Description

누구를, 언제, 무엇을 도와주는지 2~3문장으로 쓰세요. Copilot 은 이 글을 보고 에이전트를 부를지 결정하므로, 사용자가 실제로 말할 단어(회의, 메일, 보고서…)가 들어가야 잘 불립니다.

🧰 MS 도구 Copilot 에이전트가 쓸 수 있는 도구

에이전트 만들기 화면에서 고를 수 있는 Microsoft 도구입니다. 내 에이전트에 필요한 것만 켜 주세요. Studio 표시는 Copilot Studio 에서 쓰는 도구입니다.

지식 — 에이전트가 읽고 답하는 자료 (Knowledge)

메일 Mail (Outlook)
내 메일함의 메일을 찾아 읽고 요약
Teams 채팅 Teams chats
Teams 채팅·채널 메시지와 나를 멘션한 글
회의 Meetings
일정, 회의 초대장, Teams 회의 녹취록·요약
사람 People
조직도와 사람 정보 (담당자, 팀원, 상사)
SharePoint SharePoint
회사 SharePoint 사이트·폴더·파일
OneDrive OneDrive
내 OneDrive 에 있는 파일
파일 올리기 Uploaded files
Word·Excel·PDF·PPT 파일을 에이전트에 직접 올려 두기
내부 웹 검색 Internal web search
회사 인트라넷·사내 사이트에서만 찾기
외부 웹 검색 External web search
인터넷 전체(Bing)에서 공개 자료·뉴스 찾기
특정 웹사이트 Specific websites
지정한 주소(URL)의 공개 사이트만 찾기
Copilot 커넥터 Copilot connectors
Jira·ServiceNow·Confluence 같은 외부 시스템 데이터 (예전 Graph connectors)
Dataverse Dataverse Studio
Power Platform 의 업무 데이터 표
Azure AI Search Azure AI Search Studio
회사가 Azure 에 만들어 둔 검색 색인

기능 — 에이전트가 직접 하는 일 (Capabilities)

코드 실행 Code interpreter
Python 으로 엑셀 데이터 분석, 계산, 차트 만들기
이미지 만들기 Image generator
설명을 바탕으로 그림·이미지 만들기

동작 — 다른 시스템을 움직이기 (Actions)

Power Automate 흐름 Power Automate flow Studio
메일·Teams 보내기, 승인 요청, 파일 저장 같은 자동 실행
Power Platform 커넥터 Power Platform connectors Studio
Outlook·Planner·Excel 등 기본 제공 커넥터로 조회·쓰기
사용자 지정 커넥터 Custom connector Studio
기본 커넥터에 없는 사내 시스템을 직접 연결
API 플러그인 API plugin Studio
사내 REST API 를 OpenAPI 문서로 연결해 호출
MCP 서버 MCP server Studio
MCP 서버가 제공하는 도구를 에이전트에 연결
프롬프트 도구 Prompt Studio
정해 둔 AI 프롬프트(요약·분류·추출)를 도구처럼 불러 쓰기
다른 에이전트 연결 Connected agents Studio
다른 에이전트에게 일을 넘겨 함께 처리
컴퓨터 사용 Computer use Studio
API 가 없는 웹·데스크톱 화면을 대신 클릭·입력 (미리 보기)

메뉴 이름과 쓸 수 있는 도구는 회사 설정·라이선스에 따라 다를 수 있습니다.

3. Skills 스킬 / Actions → skill.md

에이전트가 어떻게 일할지 적는 설명서입니다. ① 할 수 있는 일 ② 답변 규칙(지어내지 않기, 출처 붙이기 등) ③ 언제 쓰는지 순서로 쓰면 됩니다. 처음이라면 예제 본문을 내 업무에 맞게 고쳐 쓰는 게 가장 쉽습니다.
